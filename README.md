# Hotel Vendimia Parador

Repositorio privado del sitio web oficial de Hotel Vendimia Parador, Santa Cruz, Chile.

## Objetivo

Reproducir el sitio existente en https://www.hotelvendimiaparador.cl/ sin alterar el dominio ni su funcionamiento hasta que una versión de prueba esté verificada. Posteriormente, mejorar diseño, rendimiento, idiomas y experiencia de reservas.

## Publicación

Alojamiento previsto: Netlify, conectado a este repositorio GitHub. No conectar el dominio oficial ni cambiar DNS antes de verificar el sitio completo y los registros de correo.

## Integración de reservas

Se usará el motor de reservas del nuevo channel manager. El enlace final debe validarse antes de habilitar botones de reserva; no reutilizar el enlace anterior de Reservatio.
